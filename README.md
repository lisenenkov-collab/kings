# Kings Legacy

Оригинальная 2D RPG-стратегия для Android, вдохновлённая классикой.

## Запуск
1. Откройте папку в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Запустите `app` на эмуляторе или телефоне.
4. APK: Build -> Build APK(s).

## Первый прототип
- карта мира;
- герой;
- армия;
- золото;
- переход в бой;
- пошаговый бой;
- победа и награда.

Следующий этап: полноценная система кампании, сохранения, города, рекрутирование, навыки, заклинания, предметы, AI и контент.
